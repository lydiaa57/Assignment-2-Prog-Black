# Guide for Learners of P5:

## Why learn p5?
* **Visual Programming**: Instead of just returning text, you can draw shapes, animate and create interactive sketches. This interactability keeps learners engaged and lets you play around, changing values etc which aids understanding as you are able to see what each variable and function exactly does. 
* **Simple Syntax**: It is built on JavaScript so is perfect for those familiar with this, but also great for complete beginners who will pick up a real-world language crucial in web development that will lend itself well to other JS libraries.
* **Builds creativity**: Lets learners make art, games and simulations, many of which focus on creating visually pleasant products. This is an important skill to have because as important as problem solving (which every langauge teaches) is, users won't use sites that are hard to navigate, cluttered and simply ugly.
* **Naturally teaches core concepts**: It becomes far easier to understand concepts such as variables, conditional statements, loops, functions if you can control their actions on a screen and see the results.
* **Accessible**: It is able to run in browser on [editor.p5js](https://editor.p5js.org/) which is perfect for beginners for who it is better to focus on smaller mini projects, rather than having them forced to navigate a complex IDE. The removal of this barrier also helps users focus directly on leanring p5, with only a basic understanding of HTML and CSS needed to set up projects, most of which is consistent throughout templates.

## Evaluation
p5 offers a high level of usefullness relative to the effort that it takes to learn it. Particularly because the initial learning curve is low for both those familiar with JS and beginners- because syntax is beginner friendly and there is no need to have a complex set up. One can immediatly start building which acts as great motivation and reinforces comprehension. 

p5 is a valuable becaue it reinforces key programming concepts, teaches how integrates mathematics to create products and introduces event-driven programming by considering mouse interactions. It is also a JS library so is a transferable skill necessary in web development and opens up the opportunity to progress further by trying out: pure JS, other libraries, or for more complexity frameworks like React.

But, if the learner's intention behind leanring this are primarily industry focused, this may not be the best languaged because p5 is not typically used for large scale software development project or endeavours that are preoformance-critical. Therefore, it may be better to persue other tools or soon transiton to them after following the p5 course.

Alternatives exist:
* **Processing**: This uses Java but is similar in design. It provides a GUI, and although slower in drawing, it is faster for calculations as it has additional clases and aliased mathematical functions and operations.
* **Python**: This is more beginner friendly, and personally, I find it easier. It is more versatile and widely used but often requires more set up and has a slower visual payoff. But, it has plenty of libraries such as Pygame and Turtle to use as well as plentiful materials online to learn.
* **Three.js**: This is another JS library but this one is significantly more complex and less suitable for beginners since it is the standard for 3D scenes. Logically, they are similar but Three uses more object-oriented and verbose, designed more for complex applications such as game development and project visualisations. It also requires proper set up, rather than just letting users draw straight on a canvas. Therefore, it seems to be the sensible next step for learners if they love p5 and would like to purse a harder challenge with greater real life applications, rather than an alternative to leaning p5, especially for beginners.
