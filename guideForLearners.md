# Guide for Learners of p5:

## Why learn p5?
* **Visual Programming**: Instead of just returning text, you can draw shapes, animate and create interactive sketches. This interactability keeps learners engaged and lets you play around, changing values etc which aids understanding as you are able to see what each variable and function exactly does. 
* **Simple Syntax**: It is built on JavaScript so is perfect for those familiar with this, but also great for complete beginners who will pick up a real-world language crucial in web development that will lend itself well to other JS libraries.
* **Builds creativity**: Lets learners make art, games and simulations, many of which focus on creating visually pleasant products. This is an important skill to have because as important as problem solving (which every language teaches) is, users won't use sites that are hard to navigate, cluttered and simply ugly.
* **Naturally teaches core concepts**: It becomes far easier to understand concepts such as variables, conditional statements, loops, functions if you can control their actions on a screen and see the results.
* **Accessible**: It is able to run in browser on [editor.p5js](https://editor.p5js.org/) which is perfect for beginners for who it is better to focus on smaller mini projects, rather than having them forced to navigate a complex IDE. The removal of this barrier also helps users focus directly on learning p5, with only a basic understanding of HTML and CSS needed to set up projects, most of which is consistent throughout templates.

## Background Materials
In order to sufficiently cater to all kinds of learners, I shall split this section into two parts, each having their own target audience: complete beginner, and proficiency with JS.

### Beginner:
The background materials that I would recommend need to serve the purpose of teaching the learner basic concepts (loops, conditions, functions etc) needed to create something of value. If they are younger children I would recommend starting with [Scratch](https://scratch.mit.edu/) because it is a block based language that visually will teach the logical process behind coding. However, it is unlike coding in real life so for anyone older, I would recommend [Khan Academy - Intro to JS](https://www.khanacademy.org/computing/computer-programming/programming) because it has a variety of teaching materials: talk-throughs, challenges, and projects all for free and readily available online. An alternative would be [freeCodeCamp](https://www.freecodecamp.org/learn/javascript-v9/) which is more in depth and closer to real-world coding. As this is for a proper certification and would require higher dedication to complete, I would recommend this only for this who wish to later explore other areas of JS 

### Proficiency with JS:
Background materials provided here serve the purpose of aiding the transition into more complex JS. A key resource is the [MDN Web Dev Documentation](https://developer.mozilla.org/en-US/docs/Web/JavaScript) which is more of a reference than a tutorial. It shall help strengthen underlying knowledge and helps understand performance and structure.

## Learning p5
To start with, I recommend going through the [p5 site](https://p5js.org/) as this is where I started and this had numerous benefits:
* The example section website showcases the vast uses of p5L: shapes and colour, games, 3D etc. This shows the potential of what learners could make, giving them an idea of the wide variety of applications guaranteeing they will find something that fits them. Also, each example comes with code so they are able to understand how exactly it was made. Every example, is simple demonstrating the approachability of this language.
* The tutorials section is particularly useful. One to not skip out on is the [Setting Up Your Environment One](https://p5js.org/tutorials/setting-up-your-environment/) which comes with screenshots and detailed explanations as to what every line does and why it has been included. Although a variety of different ones exist, one I particularly recommend is the [Data Structure Garden](https://p5js.org/tutorials/data-structure-garden/) because it is firstly interactive but also explores the use of: data structures like JS objects; object methods on the built-in objects; and iteration with for loops to manage multiple objects simultaneously. What I like about these tutorials is that they list the prerequisits, actually explain the code and also have what the code should look like at every step which is good for error catching. In addition, they also have ideas for what more to add (with example solutions of this too), next steps that include integrating other libraries such as node.js, mI5.js or even HTML & CSS which will great for larger projects. There are also further resources on the theory used that link the the MDN article in order to ensure that learners actually understand what they are doing, rather than mindlessly copying out code. However, if learners prefer a full video tutorial, rather than just an article format this may not be for them.

## Evaluation
p5 offers a high level of usefulness relative to the effort that it takes to learn it. Particularly because the initial learning curve is low for both those familiar with JS and beginners- because syntax is beginner friendly and there is no need to have a complex set up. One can immediately start building which acts as great motivation and reinforces comprehension. 

p5 is a valuable because it reinforces key programming concepts, teaches how integrates mathematics to create products and introduces event-driven programming by considering mouse interactions. It is also a JS library so is a transferable skill necessary in web development and opens up the opportunity to progress further by trying out: pure JS, other libraries, or for more complexity frameworks like React.

But, if the learner's intention behind learning this are primarily industry focused, this may not be the best language because p5 is not typically used for large scale software development project or endeavours that are performance-critical. Therefore, it may be better to pursue other tools or soon transition to them after following the p5 course.

Alternatives exist:
* **Processing**: This uses Java but is similar in design. It provides a GUI, and although slower in drawing, it is faster for calculations as it has additional classes and aliased mathematical functions and operations.
* **Python**: This is more beginner friendly, and personally, I find it easier. It is more versatile and widely used but often requires more set up and has a slower visual payoff. But, it has plenty of libraries such as Pygame and Turtle to use as well as plentiful materials online to learn.
* **Three.js**: This is another JS library but this one is significantly more complex and less suitable for beginners since it is the standard for 3D scenes. Logically, they are similar but Three uses more object-oriented and verbose, designed more for complex applications such as game development and project visualisations. It also requires proper set up, rather than just letting users draw straight on a canvas. Therefore, it seems to be the sensible next step for learners if they love p5 and would like to purse a harder challenge with greater real life applications, rather than an alternative to leaning p5, especially for beginners.
